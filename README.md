# SaveBite
AI-powered grocery intelligence and food-waste management platform using React, Node.js, Supabase, IoT telemetry, and machine learning to reduce food waste and enable smarter shopping.

> **Tagline**: *"Save Food. Save Money. Waste Less."*

## Repository Structure

- `frontend/` — Mobile-first React + Vite web application with Tailwind CSS, Recharts, and IoT dashboard.
- `backend/` — Express / Node.js API services.
- `ai/` — Machine learning models and recipe intelligence.
- `iot/` — Sensor firmware and MQTT telemetry handlers.

## Getting Started with Frontend

```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

Visit `http://localhost:5173/` in your browser. Detailed API contracts and specifications can be found in [frontend/README.md](file:///d:/Projects/Hakathon/SaveBite/frontend/README.md).
